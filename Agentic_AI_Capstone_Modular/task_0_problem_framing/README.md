# Agentic AI Capstone - Modular Solution

This repository contains the reference implementation for the 9-Phase Capstone Project.
Each phase has a corresponding module in the `task_` directories.

## Phase Mapping

| Phase | Description | Directory | Key File |
| :--- | :--- | :--- | :--- |
| **1** | **Problem Framing** | `task_0_problem_framing` | `problem_statement.md` |
| **2** | **Baseline Agent** | `task_1_python_baseline` | `baseline_agent.py` |
| **3** | **LLM Integration** | `task_2_llm_integration` | `prompt_experiment.py` |
| **4** | **Knowledge & Retrieval** | `task_3_embeddings_retrieval` | `rag_pipeline.py` |
| **5** | **Tool Usage** | `task_4_tool_using_agent` | `tools.py` |
| **(Aux)** | *Architecture* | `task_5_agent_architecture` | `architecture.md` |
| **6** | **Planning & Memory** | `task_6_planning_memory_rag` | `memory_agent.py` |
| **7** | **Adaptive Behavior** | `task_7_adaptation_learning` | `adaptation.py` |
| **8** | **Deployment** | `task_8_deployment_monitoring` | `monitoring_mock.py` |
| **9** | **Evaluation** | `task_9_evaluation_ethics` | `evaluation.md` |

## How to Run
Most scripts are standalone Python simulations.
Example:
```bash
python task_1_python_baseline/baseline_agent.py
```
